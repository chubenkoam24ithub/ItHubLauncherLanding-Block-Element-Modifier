Штаб технической поддержки

Лаунчер не запускается на Ubuntu 20.04. Что делать?

Откройте терминал и убедитесь, что у вас установлена Java 17+. При необходимости выполните `sudo apt install openjdk-17-jre`.

Как перенести свои миры и базы данных?

Лаунчер автоматически импортирует сохранения из стандартной директории .minecraft при первом запуске.
