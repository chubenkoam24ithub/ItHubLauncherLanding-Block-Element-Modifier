## Описание проекта
Проект представляет собой одностраничный сайт (Landing Page) для скачивания игрового клиента **IThubMinecraft Launcher**. Интерфейс разработан с акцентом на современный геймерский дизайн (Glassmorphism, неоновые свечения, темная тема).

Главная архитектурная особенность проекта — строгая реализация **методологии БЭМ (Блок, Элемент, Модификатор)** для структурирования стилей. Это демонстрирует навык проектирования компонентной архитектуры пользовательских интерфейсов. Использование БЭМ обеспечивает независимость блоков, предсказуемость каскада стилей, отсутствие конфликтов селекторов и легкость масштабирования проекта.

Основные технологии и архитектурные решения:
- **HTML5 / CSS3** — семантическая верстка и стилизация без использования сторонних UI-фреймворков.
- **БЭМ-архитектура** — плоская структура селекторов, использование миксов (mix) для независимого позиционирования компонентов и модификаторов (`--`) для управления состояниями (например, различные цветовые схемы кнопок для разных ОС).
- **Адаптивный дизайн (Responsive Web Design)** — гибкая сетка (Grid/Flexbox) и медиа-запросы для корректного отображения контента на мобильных устройствах.
- **CSS-фильтры** — динамическое управление цветом векторной графики без необходимости перерисовки исходных SVG-файлов.
